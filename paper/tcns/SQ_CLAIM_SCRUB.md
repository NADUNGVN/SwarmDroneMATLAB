# SQ claim-scope scrub

**Audit date:** 2026-09-08  
**Source:** paper/tcns/manuscript/tcns_information_limits.tex

The source was searched case-insensitively for: first, novel, optimal,
fundamental, impossible, always, guarantee, universally, all multi-agent, all
UAV, free information, minimum information, exact closed-loop action value,
all ten, and minimum dimension/number.

| Term / occurrence class | Decision |
|---|---|
| first | The only surviving prose uses are “velocity-first integrator” and an ordered “First derive...” instruction; neither is a priority claim. |
| novel | No positive novelty claim survives. Uses such as “not new” and “no new trigger” attribute or deny novelty. |
| optimal | Prior work is accurately described as proving optimal structures; the interval midpoint is mathematically minimax-optimal. The manuscript explicitly makes no optimal-scheduler claim. |
| fundamental / impossible / guarantee | No unqualified claim survives. |
| always / universally | Both occur only in explicit disclaimers: the paper does not say feedback is always uneconomic or adaptive communication universally inferior. |
| all multi-agent / all UAV | No such generalization occurs. |
| free information | No claim of free information occurs. The paper explicitly states that a one-dimensional statistic is not free and limits piggybacking to no additional packet under the packet-frequency metric. |
| minimum information | The formal claim is restricted to the minimum number of instantaneous, noiseless, arbitrary-precision, real-valued linear scalar statistics. It is not generalized to arbitrary encoders, bits, packets, data rate, sensor count, or functional-observer order. |
| all ten | Every all-ten system claim now says “structural unit-response value functionals.” The paper explicitly excludes zero and specially cancelling physical responses. |
| exact action value | Generic theorem language occurs only after the fixed-response object is defined. Abstract, research question, key empirical captions, interpretation, and conclusion use conditional fixed-response finite-horizon benefit/value where needed. |
| N=5 coalition | Every ownership claim is limited to the evaluated graph, global stacked formation-error output, identity weighting, H=25, and declared observation maps; localized objectives may yield smaller coalitions. |
| empirical frontiers | Captions and limitations identify five paired development seeds and descriptive/non-inferential use. O1 is privileged and nondeployable. |
| economics | ACK charging is described as an ACK-like packet-frequency sensitivity, not the measured acquisition cost of the all-agent statistic. |

**Result:** no unscoped priority, optimality, universality, impossibility, or
minimum-information claim remains.

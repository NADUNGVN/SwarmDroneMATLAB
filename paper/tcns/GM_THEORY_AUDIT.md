# GM theory generalization and proof audit

**Scope:** finite-dimensional sampled linear/affine closed loops with a fixed
communication-action response.  **Formation instantiation:** the frozen Gate-3
N=5 unsaturated sampled double-integrator model.  No scheduler is proposed.

## 1. Generic action-value representation

Let a no-action finite-horizon output be

\[
z=Fx+r,
\]

and let a fixed candidate action add \(g_a\).  For symmetric
\(Q\succeq0\), define the benefit (no-action cost minus action cost)

\[
q_a(x)=\|Fx+r\|_Q^2-\|Fx+r+g_a\|_Q^2.
\]

Direct expansion gives

\[
q_a(x)=\ell_a^\top x+c_a,
\quad
\ell_a=-2F^\top Qg_a,
\quad
c_a=-2r^\top Qg_a-g_a^\top Qg_a.
\]

A positive scalar normalization multiplies both coefficients without changing
identifiability or sign.  This affine representation requires that the action
response is fixed at the decision point.  If \(g_a\) depends on an unobserved
state, the generic affine theorem cannot be invoked without augmenting the
state or conditioning on a hypothesis.

## 2. Exact-value identifiability

**Theorem 1 (action-value functional observability).**  Let the acting agent
observe \(o=Cx+d_o\).  On \(\mathbb R^n\), or locally on a set containing an
open relative neighborhood along \(\ker C\), the exact value \(q_a(x)\) is a
function of \(o\) if and only if

\[
\ell_a\in\operatorname{row}(C).
\]

**Proof.** If \(\ell_a=C^\top\alpha\), then
\(q_a=\alpha^\top(o-d_o)+c_a\).  Conversely, equal observations for
\(x\) and \(x+v\), \(v\in\ker C\), must imply equal values.  Hence
\(\ell_a^\top v=0\) for every \(v\in\ker C\), and therefore
\(\ell_a\in(\ker C)^\perp=\operatorname{row}(C)\).  QED.

This equivalence is a specialization of classical functional observability,
not a claim of a new generic rank theorem.  The contribution is its use with
the exact marginal value of a communication action and the sign/economic
consequences developed below.

## 3. Finite observation history

For

\[
x_{t+1}=A_0x_t+a_0,\qquad o_t=Cx_t+d,
\]

the stacked length-L observation has state-dependent part

\[
\mathcal O_Lx_0,\qquad
\mathcal O_L=\operatorname{col}(C,CA_0,\ldots,CA_0^L).
\]

At decision time L, \(q_a(x_L)\) has coefficient
\(\ell_{a,0}=(A_0^L)^\top\ell_a\) in \(x_0\).  Thus

\[
q_a(x_L)\text{ is identifiable from }o_{0:L}
\iff
(A_0^L)^\top\ell_a\in\operatorname{row}(\mathcal O_L).
\]

Known affine offsets affect only the value constant.  By Cayley--Hamilton,
the row space generated by \(C,CA_0,\ldots\) stabilizes no later than the
ordinary n-step observability horizon.  Beyond that point, additional samples
add no observation directions.  They cannot recover a decision-time value
whenever its propagated coefficient remains outside the stabilized row space.
A hidden mode annihilated by the dynamics can cease to affect a later value;
that is loss of dependence, not information recovery.  New measurements,
packets, or side information instead change the map.

## 4. Sign decidability

Let \(q(x)=a^\top x+b\), and let

\[
\mathcal X(o)=\{x\in\mathcal X:Cx+d=o\}.
\]

Define \(q_{\min}(o)=\inf_{x\in\mathcal X(o)}q(x)\) and
\(q_{\max}(o)=\sup_{x\in\mathcal X(o)}q(x)\).

**Theorem 2 (sign ambiguity).** If
\(q_{\min}(o)<0<q_{\max}(o)\), no deterministic map of \(o\) can equal the
sign of the exact value for every state in \(\mathcal X(o)\).

**Proof.** The same observation is compatible with one negative-value and one
positive-value state.  A deterministic map assigns them the same decision,
so it is wrong for at least one.  QED.

Let \(P_C=C^\dagger C\), \(a_\perp=(I-P_C)a\), and consider the local
Euclidean fiber \(x=x_0+v\), \(v\in\ker C\), \(\|v\|_2\le\rho\).  Its exact
value interval is

\[
[q(x_0)-\rho\|a_\perp\|_2,\ q(x_0)+\rho\|a_\perp\|_2].
\]

The result is local to the declared operating set.  It proves neither that a
Bayesian policy cannot be useful nor that every information state is
ambiguous.

## 5. Minimum supplementary linear information

Stack p action-value coefficients as the rows of \(L\in\mathbb R^{p\times n}\)
and define

\[
L_\perp=L(I-C^\dagger C).
\]

**Theorem 3 (minimum statistic dimension).** The minimum number of additional
linear scalar statistics \(Hx\) required to identify all p values is

\[
r_\star=\operatorname{rank}(L_\perp).
\]

**Proof.** If the values are identifiable from \([C^\top,H^\top]^\top x\),
the projections of the rows of H onto \(\ker C\) must span every row of
\(L_\perp\); therefore H requires at least \(\operatorname{rank}(L_\perp)\)
independent rows.  Conversely, choose H as any row basis of \(L_\perp\).
Then each row of L is the sum of a row-space(C) component and a row-space(H)
component, so all values are identifiable.  QED.

For one nonidentifiable action, one scalar is mathematically sufficient.  It
does not follow that one agent owns that scalar or that one packet can acquire
it.

## 6. Coalition ownership

For agent maps \(C_i\), let

\[
C_{\mathcal S}=\operatorname{col}_{i\in\mathcal S}C_i.
\]

**Corollary 1.** A fixed value is identifiable by coalition \(\mathcal S\) if
and only if \(\ell\in\operatorname{row}(C_{\mathcal S})\).  A minimum owning
coalition solves

\[
\min_{\mathcal S}|\mathcal S|\quad
\text{s.t. }\ell\in\operatorname{row}(C_{\mathcal S}).
\]

This is a functional-sensor-selection problem.  It characterizes information
ownership, not the messages, protocol, latency, or energy needed to aggregate
the statistic.

## 7. Feedback-economic corollary

At formation error E, let \(C_P(E)\) be the interpolated periodic-frontier
cost, D the DATA cost of an informed action policy, and let supplementary
information type t have event rate \(R_t\) and price \(\eta_t\).  Pareto
benefit requires

\[
D+\sum_t\eta_tR_t<C_P(E).
\]

For one feedback stream with rate A, its break-even price is

\[
\eta^\star=\frac{C_P(E)-D}{A}.
\]

This is an accounting identity and a co-design feasibility condition, not an
optimality theorem.  Payload airtime, packet frequency, and piggybacking must
be costed under the chosen network model; a scalar statistic is not free.

## 8. Mapping to Gate 3

In the formation model, \(x=\xi_k\in\mathbb R^{99}\),
\(z=\operatorname{vec}(Z_k)=F_H\xi_k+r_H\), \(Q=I\), and
\(g_a=\operatorname{vec}(G_{ij,s})\).  Including the frozen success
probability and follower normalization yields

\[
q_{ij,s}=-\frac{2p_s}{m}g_{ij,s}^\top(F_H\xi_k+r_H)
-\frac{p_s}{m}\|g_{ij,s}\|_2^2.
\]

Belief weighting is coefficient-wise over fixed memory hypotheses; it is not
evaluation at an expected memory.  The strongest implemented sender map is
\(C_j\); under a held-memory no-delivery history its finite-history map is
\(\mathcal O_{j,L}\).

All ten payloads fail the row-space condition.  Reduced dimensions are 93
(ordinary) and 90 (pinned leader); complete-history ranks are 9--27 and 9,
respectively.  Normalized projection residuals are strictly positive.
Exhaustive N=5 enumeration finds four additional agents are required for
each sender: only the five-agent coalition identifies each fixed-action
missing scalar in this topology.  This is an N=5 case result, not a universal
all-agent requirement.

Two preregistered reachable witnesses (ordinary 1->5 and pin 1->4) have
identical complete leader observations, sent-packet record, ACK-free belief,
and action responses but opposite expected and actual-receiver value signs.
Commands remain below 0.065 m/s^2 versus the 2 m/s^2 limit.

## 9. Proof audit

| Item | Status | Audit boundary |
|---|---|---|
| Fixed-response affine value | proved and numerically exact | state-dependent unknown action response must be augmented/conditioned |
| Current information iff | proved | classical functional observability specialization |
| Finite history iff | proved | fixed affine dynamics and observation map |
| Sign ambiguity | proved | local/operating-set statement |
| Euclidean-fiber interval | proved by Cauchy--Schwarz with attainable endpoints | Euclidean fiber only |
| Minimum statistic dimension | proved | linear scalar statistics only |
| Coalition criterion | proved | acquisition protocol/cost not implied |
| N=5 ten-payload application | validated numerically from implementation matrices | numerical rank applies only to frozen model/topology |
| Dynamic sign relevance | full reachable simulation for two preregistered payload classes | no all-ten dynamic claim |
| Bayesian conditional expected value | outside scope | no impossibility claim against a specified prior/filter |

No unresolved gap invalidates the stated theorems.  The main reviewer risk is
novelty depth: the exact-value iff condition and coalition selection inherit
functional-observability theory.  The manuscript must therefore make the
action-value/sign/economics synthesis and the formation counterexample—not
the row-space lemma alone—the contribution.

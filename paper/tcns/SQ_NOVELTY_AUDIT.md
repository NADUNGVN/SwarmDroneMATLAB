- partial-information action-value regret;

- 2025–2026 goal-oriented communication + networked control;
- 2025–2026 functional/structural/sample-based observability.

The search covered IEEE Xplore/publisher records where accessible, Crossref
metadata, Google-indexed scholarly records, author/institution repositories,
and an explicit search for recent public working manuscripts.

## Direct-collision criterion

A direct collision would need to combine, in substantially the same problem:

1. a fixed-response finite-horizon communication-action benefit represented as
   an affine closed-loop state functional;
2. exact sender-information identifiability of that functional;
3. compatible-set value radius or unavoidable binary communication-decision
   regret;
4. minimum instantaneous linear supplementary-statistic dimension for
   multiple actions; and
5. distributed ownership/acquisition cost of those statistics.

No located archival work contains that combination.

## Nonarchival terminology-adjacent manuscript

A public working manuscript in
[ahb-sjsu/geometric-observation](https://github.com/ahb-sjsu/geometric-observation/blob/master/paper/ot-estimation-control.tex)
was found by the exact combination search. Its inspected file was updated on
2026-08-30 and combines functional-observability terminology with
consumer-relative value of observation. Its stated mechanism is a
consumer-induced covariance geometry, including query-only recovery from a
consumer. It does not state the sender-information row-space iff application,
the local exact-value interval regret, or the minimum missing instantaneous
linear-statistic result used here. It is therefore a terminology/conjunction
threat, not a direct theorem collision. Because no archival publication was
located, the manuscript does not cite it as established prior art; this audit
records it transparently.

## Submission interpretation

The final defensible distinction is:

> Prior work designs or analyzes sensing, communication, and control under a
> declared information model. This manuscript uses classical functional
> observability to audit a narrower object—the conditional fixed-response
> communication benefit—and adds a quantitative compatible-value/decision
> limit, multi-action missing-statistic dimension, implementation-faithful
> reachable witnesses, and an acquisition-cost separation.

This wording is an audit conclusion, not a priority claim.
